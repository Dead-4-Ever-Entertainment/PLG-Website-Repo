Game Features

What makes Purple Lotus Guild unique.

Code as Gameplay

Write real code to control your hero. Movement, sensing enemies, attacking, using items, shopping, and crafting are all done through function calls like hero.attack() or hero.buy("minor_hp_potion").

Educational Lessons

Structured lessons guide you from printing "Hello" to managing inventory, equipping gear, and advanced combat. Lessons are context-aware and tied to specific scenes.

Crafting & Professions

Alchemy, metalworking, woodworking, textile, leatherworking, and enchanting. Use stations in town and recipes from the game data. Races give profession XP bonuses.

Combat System

Turn-based code-driven combat with class skills, weapon skills (tiered by level), status effects, and resource management. Face monsters from the bestiary with unique drops.

Equipment & Items

Weapons, armor, rings, necklaces, capes, potions, food, and more. Rarity bands, enchants, and loot tables drive progression. Equip via code.

Save & Progress

Save your game, load previous slots, and continue your campaign.

Example Code

# Explore and fight
if hero.enemy_nearby():
    hero.attack()
else:
    hero.move_right()

# In town
hero.enter_shop("alchemist")
hero.buy("minor_hp_potion")
hero.equip("copper_short_sword")
hero.rest()
